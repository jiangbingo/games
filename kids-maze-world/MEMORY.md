# Memory

- 项目基于React 19、Vite、Tailwind 4，适合以一个全屏路由承载游戏。
- 游戏技术路线为Babylon 2D正交相机与程序化网格，不引入GLB或物理系统。
- 关键高风险点为关卡生成的可解性与多输入方式的单格移动一致性，均需通过`?demo`和截图验证。
- 所有大图资源使用`/manus-storage` URL，避免将大文件写入项目目录。
- 儿童体验约束：无失败扣分；碰壁有温和反馈；提供撤销、重玩和有限提示；控制按钮最小触控面积保持48px以上。
- 视觉验证显示Babylon正交迷宫与方向控件在1280x720画面中可见；透明画布需要在`Engine`配置中显式开启`alpha: true`，否则会以深色底遮盖观察板背景。
- 已根据视觉审阅将中央迷宫设为观察板主视觉，并将关卡信息转为便签、邮票和方向石语汇；生成的森林地图用于主舞台背景层与关卡总览。
- 已接入BigSoundBank授权为CC0的55秒真实森林户外录音；浏览器性能记录确认其仅在孩子或家长首次主动操作后才被请求，避免占用首屏加载。
- 12个主题均映射独立角色、终点物、背景道具插画和互动音色；当前主题只请求一张宽幅视觉资产，已在花雨与雪松主题抽检。
- 家长面板已验证展示每日探索时长、关卡与贴纸进度、声音设置、每日提醒，并使用首次点击改为“再次确认清空”的非破坏性双确认重置流程。
- 已验证雪松主题自动通关后会出现独立绘本剧情卡；完成故事后才衔接未收集主题的贴纸奖励，已收集主题不会重复奖励。
- 每周报告以本地日期为维度，展示最近7天探索时长、当周新增关卡和贴纸；空日期不再显示误导性的最小柱状高度。
- 已完成枫叶小火车主题的端到端验证：自动送达后显示专属剧情，剧情关闭后显示新贴纸；家长周报同步显示当日新增1封小信与1枚贴纸。
- 已验证桌面端Enter上下文确认的完整流程：剧情卡Enter关闭、贴纸奖励Enter收下、通关状态Enter自动进入下一封信；文本控件与弹层打开时不会触发迷宫移动。
- 已验证桌面端快捷键帮助卡可由右上角“按键”打开，并可用Esc即时关闭；帮助卡明确说明方向键/WASD移动、Enter/Space确认和Esc关闭。
- 已验证家长面板在桌面端打开后，Esc可立即关闭且不会触发重置或声音设置等其他操作。
- 已验证草莓茶会主题通关后，空格键可作为确认键关闭剧情并推进到贴纸奖励层。
- 已验证贴纸奖励层可由Esc关闭；草莓茶会关卡中D键已被迷宫输入处理器接收并产生碰壁反馈，确认WASD映射生效。
