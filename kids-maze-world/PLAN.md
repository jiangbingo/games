# Game Plan: 迷宫小小探险家

## Risk Tasks

### 1. 数据驱动的100+迷宫生成与难度控制
- **Why isolated:** 仅随机生成会出现无解、路径过长或对学龄前儿童不友好的布局；100个关卡还必须保持可复现与视觉主题变化。
- **Approach:** 使用确定性深度优先迷宫生成器，以关卡编号作为种子；先构建完美迷宫，再依据章节限制网格大小、最长死路和推荐步数。启动时用广度优先搜索验证起点到终点唯一可达；将100个关卡存为可重建的配置，而非手写静态迷宫。
- **Verify:** 从第1、25、50、75、100和第120关取样，均可由求解器找到路径；第1组保持5x5–7x7，小手点击不误触；第100+关存在更多分叉但路径、角色与终点均清晰可见。

### 2. 网格输入、动画与状态切换
- **Why isolated:** 键盘、点击方向盘与触屏滑动需收敛至同一移动队列，且儿童需要感到每次操作都被可靠接收。
- **Approach:** InputManager将原始事件转换为`up/down/left/right`语义动作；GameWorld在角色静止时执行一个格子的移动，播放固定时长位移；碰壁与通关使用独立短动画，并允许撤销栈恢复上一步。
- **Verify:** 键盘、方向按钮和单指滑动均只走一格且方向一致；走路→碰壁、走路→通关、撤销→走路的过渡不跳格、不重复计步；在窄屏方向盘仍易点按。

## Main Build

构建全屏Babylon 2D迷宫舞台与React外层界面。游戏提供120个可重建关卡，按五个森林主题分组；每局展示任务、步数、叶片收集进度、撤销、重玩、提示和关卡导航。世界地图和森林插画作为主题场景，迷宫、角色、障碍、足迹和庆祝反馈由程序化2D网格组成。

- **Assets:**
  - `visual-target`（`/manus-storage/maze-forest-visual-target_2d38166e.png`）作为成品视觉QA参照。
  - `world-map`（`/manus-storage/maze-forest-world-map_92a52f79.png`）用于关卡选择地图。
  - `leaf-compass-logo`（`/manus-storage/maze-leaf-compass-logo_cc91d486.png`）用于导航与品牌识别。
  - `forest-decorations`（`/manus-storage/maze-forest-decorations_7d3188a9.png`）用于世界地图与迷宫外侧装饰。
- **Verify:**
  - 角色移动方向与键盘、方向按钮、滑动输入一致。
  - 路径不可越过，碰壁不会增加步数，撤销可恢复角色位置与步数。
  - 进度、目标、提示、重玩与章节切换均可用，文本与按钮无溢出。
  - 关卡1至120可通过关卡选择器访问，并保存在本机浏览器进度中。
  - 小狐狸、目标、迷宫墙与交互提示具有符合视觉目标的配色、轮廓与尺度。
  - 桌面和移动视口均无明显视觉缺失、占位素材或控制台错误。
  - `?demo`使用确定性的自动求解路径，让截图展示真实通关状态。
