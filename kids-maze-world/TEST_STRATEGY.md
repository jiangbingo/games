## 2. 支持矩阵

此表区分**目标支持**与**本次交接前可追溯验证**。不要把“目标支持”写成已验证结论。

| 平台 | 目标支持 | 当前可追溯状态 | 每次重大交互改动的最低检查 |
|---|---|---|---|
| iPad Safari，横屏 | 必须 | 历史视觉 / 交互抽检；无型号版本记录。 | 手指跟随滑动、通关、声音、家长面板。 |
| iPad Safari，竖屏 | 必须 | 历史视觉 / 交互抽检；无型号版本记录。 | 无重叠、成功条位置、滚动弹层、触控安全区、手指跟随。 |
| macOS Safari | 推荐 | 未建立正式验收记录。 | 首屏、键盘、Web Inspector console。 |
| 桌面 Chromium | 推荐 | 桌面键盘关键路径曾手工验证。 | Arrow / WASD / Enter / Space / Esc。 |
| Android Chrome | 尽力支持，不作为当前承诺 | 未验证。 | 首屏、滑动、方向盘、声音策略。 |
| 低带宽 / 省流 | 尽力支持 | 代码实现检测 `2g` / `slow-2g` / `saveData`；未建立网络实验记录。 | 首屏可操作，环境音不阻塞或不请求。 |

## 3. 建议固化的自动化测试

已使用现有 Vitest 依赖，并在 `package.json` 中提供 `"test": "vitest run"`。测试文件与源代码同目录存放；后续继续扩展，不引入重量级框架。

| 测试文件 | 最低断言 |
|---|---|
| `client/src/game/maze.test.ts` | **已覆盖**（2026-08-30）：120 关相同 seed 产生相同墙体；每关 BFS 能到终点；路径相邻、不过墙；边界墙存在；相邻格墙对称。 |
| `client/src/game/GameWorld.test.ts` | **已覆盖** 120 关路径可解、路线邮票收集/重开、收集后撤销仍保持已收集，以及同关卡重建；后续补充移动一格、碰壁不计步、提示上限和通关锁定。 |
| `client/src/game/follow.test.ts` | **已覆盖**（2026-08-30）：手指位移阈值判定、主导轴选择、世界坐标 y 向上、连续拐弯、消费恰好一格且不可变。 |
| `client/src/game/activity.test.ts` | 本地日期格式、7 天窗口、空记录、重复关卡 / 贴纸去重。需先抽出可注入 storage / clock。 |
| `client/src/game/themePresentation.test.ts` | 12 个主题均有图片、故事、音色、伙伴、终点；资源 URL 均以 `/assets/` 开头。 |
| `client/src/components/GameCanvas.test.tsx` | 仅在适当重构后添加；优先测试每日日期 key、Esc / Enter 优先级和弹层状态，不要直接单测 Babylon 绘制。 |

修改测试架构时，保持 `GameWorld` / `maze.ts` 无浏览器框架依赖；这是最容易稳定测试的层。

## 4. 手工回归用例

| ID | 场景 | 步骤 | 预期 |
|---|---|---|---|
| G-01 | 关卡加载 | 清空测试用 localStorage 后打开首页。 | 从第 1 关开始，迷宫和方向盘可见。 |
| G-02 | 移动与碰壁 | 手指按住画布拖动（跟随移动，2026-08-30 起替代方向盘）、键盘方向键，随后撞墙。 | 手指滑动狐狸即跟随、一次快甩可连走多格；碰壁不增加步数、可顺势拐弯；每次有效操作一格。 |
| G-03 | 撤销 / 重来 / 提示 | 完成数步后依次点击三个工具。 | 状态、步数和提示符合文案，未卡死。 |
| G-04 | 通关奖励 | 用 `?demo` 或手动通关未收集主题。 | 剧情 → 贴纸 → 下一关顺序正确。 |
| G-05 | 已收集贴纸 | 再次通关同主题。 | 不重复发放同一贴纸，仍可进入下一关。 |
| G-06 | 路线邮票 | 沿正确路径经过六边形邮票，随后撤销一步并重来。 | 任务卡逐枚更新、场景邮票消失；**撤销后邮票仍保持已收集**，重开后本关邮票恢复。 |
| K-01 | 桌面快捷键 | 打开 / 关闭主要弹层，测试 Enter、Space、Esc、Arrow、WASD。 | 不误触原生输入控件，Esc 按约定优先级关闭。 |
| P-01 | iPad 横屏 | 真实 Safari 打开首页并游玩一关。 | 控件不遮挡、方向盘易点、迷宫可读。 |
| P-02 | iPad 竖屏 | 旋转设备后游玩、通关并打开家长面板。 | 安全区有效、弹层可关闭 / 滚动、成功条不压方向盘。 |
| A-01 | 首次音频 | 刷新后不操作，观察网络；再主动点击。 | 刷新不拉取 / 自动播放环境音；交互后按设置播放。 |
| D-01 | 家长数据 | 通关、调整时长、重置进度。 | 关卡 / 贴纸重置符合说明；时长和周报行为与产品定义一致。 |
| R-01 | 发布资源 | 对生产或预览 URL 访问首页、logo、主题图、MP3。 | 都返回 200，无 `/manus-storage/`。 |

Home Screen 安装、全屏 / Safe Area、离线冷启动、后台恢复和受控更新不在本表重复维护，统一按 `IPAD_PWA_TEST_CHECKLIST.md` 执行并归档结果。

## 6. 发布门禁

生产发布前应至少满足：所有自动化测试通过、`pnpm check`、`pnpm build`、`git diff --check` 通过；P1 / P2 缺陷已评估；目标 iPad Safari 关键流程有本轮实机记录；生产健康检查人和回滚目标明确。若任一条件缺失，发布结果应标记为“受限验证”，并由所有者决定是否承担风险。
