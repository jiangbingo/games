### 0.4 全员通用硬性标准（每个游戏验收必含，不再逐游戏重复）

1. **暗色模式三坑**（根站深色体系既有复发坑）：反馈面用 tint 令牌不用固定色；`display` 不得击穿 `[hidden]`（拼音火车/pipe-puzzle 的 H 级教训）；emoji 拼图/复杂图形用 SVG 背景精灵而非 emoji 直排（tadpole 教训）
2. **主音量**：所有 WebAudio 合成音效走 `_ensure()` + volume 守卫模式（照 hand-clap/whack-a-mole），TTS 同随主音量
3. **触屏**：`touch-action: manipulation` 全覆盖；可点目标 ≥64px；幼儿交互优先点选，拖拽必须有 ≥48px 吸附容差
4. **键盘/读屏**：所有答案选项可 Tab 聚焦 + Enter 激活 + 正确 aria 标签；`prefers-reduced-motion` 时动画降级为即时状态切换
5. **注册三处**：index.html 卡片（stat-games 计数 +1）+ tools/build-cf-pages.mjs pages 数组（含注释页数）+ sw.js PRECACHE（含头注释页数）
6. **E2E**：Playwright（/tmp 环境，`/opt/homebrew/bin/node`），每模式整局通关断言 + 零 pageerror
7. **审查**：双审查员并发对抗式（逻辑竞态 + UX/无障碍各一），按【概率×影响】只修 H/M
8. **行数**：目标 ≤850 行（tadpole 875 先例）；超线则外置数据到 `js/games/<game>-data.js`，不动交互逻辑

## 1. T4-2 奇妙修理岛（repair-island.html）

**gameId** `repair-island` ｜ **建议批次** 5-B ｜ **品类** 🧠 逻辑思维（情景问题解决） ｜ **年龄** 3-6 岁 ｜ **卡片** 🔧 ｜ **accent** `#d63031`
**一句话**：东西坏了不要扔，找对工具、按对步骤，修好它！

### 模式结构（四模式，对齐学习岛信息架构）

1. **找对工具**（tool-match，点选）
   - 题面出示一个「坏了的物品」情景卡（emoji 合成 + 一句话病症：「小汽车的螺丝松了 🔩」「气球瘪了 🎈」），下方 3-4 张工具卡（🪛🔨🔧🧹🧽🩹），点选正确工具
   - 答对：工具飞向物品 + 修好动效（kui-pop）+ 病症文案变「修好啦 ✅」；答错：工具抖动（kui-shake）留题重试
   - 题库首版 12 题，每题 { item, symptom, tool, distractors[3] }；干扰工具从「同场景易混工具」池取（修桌子给🧹不给🪛）
2. **找故障**（find-broken，点选场景）
   - 一幅 4-6 件物品的场景排布（CSS 卡片网格，每件物品一个 emoji + 修饰），其中 1 件是坏的（缺轮的🚲、歪灯罩的💡、破窗的🏠、漏气的🛞）
   - 点选坏的那件；点好的物品它「眨眼/摇摆」表示自己没问题（无惩罚）；点对进入修好动画
   - 场景首版 6 个（车库/客厅/院子/玩具房/街道/厨房），坏法用 emoji 替换 + CSS 变形（rotate/缺件）表达，不画新素材
3. **修好它**（fix-steps，点选排序——复用 life-skills 穿衣顺序交互骨架）
   - 目标物品出示 + 打乱的 3-5 步修理步骤卡，按正确顺序点入「修理台」；步骤例：修玩具车 = 装轮子🛞 → 拧螺丝🪛 → 贴贴纸✨
   - 步骤池首版 6 物品（玩具车/木马/积木塔/风筝/小凳子/布娃娃）× 3-5 步；错序卡片抖回手上
   - 全部正确后播放「开机测试」动效（物品左右摇摆 + 音效）
4. **零件补位**（shape-parts，图形推理点选）
   - 洞洞板出示：一个物品轮廓图（SVG 简笔：风车/机器人/小火车）缺 1 块零件（特定形状×颜色），从 3-4 个干扰零件中选对的补上，补上即整个轮廓点亮
   - 轮廓 SVG 首版 4 个，每块零件是 10-20 行 path 的几何图形（圆/方/三角/星 + 三色系），纯 CSS/SVG 绘制

### 难度

AdaptiveDifficulty（windowSize 5）：L1→L2 工具/零件选项 3→4、干扰相似度升（同色不同形 → 同形不同色）；L2→L3 排序题 3 步→5 步、找故障场景物品 4 件→6 件。模式内答错留题重试（全站约定）。

### 音效语音

修好音效 = WebAudio 上行双音（correct 变体）；「开机测试」= 三连短音上行；病症文案 TTS 朗读（zh-CN，随主音量）；工具卡 aria-label = 工具名。

### 素材与行数

全 emoji + CSS 变形 + 4 个简笔 SVG 轮廓。预估 ~850 行；超线砍法：找故障场景 6→4，或零件补位轮廓 4→3。

### 验收标准（E2E）

四模式各整局通关结算星级；找故障模式点「好物品」无惩罚断言；排序模式错序抖回断言；自适应有升降路径；键盘 Tab/Enter 走通一题；三处注册 + hub 计数 23→24。

## 2. T4-4 科学探索实验室（science-lab.html）

**gameId** `science-lab` ｜ **建议批次** 5-A（先行） ｜ **品类** 🌈 认知启蒙·科普 ｜ **年龄** 3-6 岁 ｜ **卡片** 🔬 ｜ **accent** `#079992`
**一句话**：动手试一试，看看种子怎么长大、小动物爱吃什么。
**MVP 边界**：首版只做「植物 + 动物食性」两主题，食物链传递、天气、水循环等后续主题按游玩数据追加（每主题一个 mode 插槽）。

### 模式结构（三模式）

1. **种一棵植物**（grow-plant，顺序互动）
   - 目标：把种子养成开花的植物。底部工具栏 4-6 个动作卡（🌰播种 / 💧浇水 / ☀️晒太阳 / 🧺施肥 / 🪢搭支架 / ✂️修剪），上方是生长舞台
   - 玩法：按植物需求顺序点动作卡；正确动作播放阶段动画（四阶段：🌰→🌱→🌿→🌻，emoji 递进 + CSS 高度/scale 过渡 + 水滴阳光粒子）；漏步或顺序错 = 舞台轻微摇头 + 提示音，不惩罚可重试
   - 首版 3 株植物（向日葵：播种→浇水→晒太阳→浇水；番茄：+施肥步骤；郁金香：+顺序差异），每株 4-6 步
   - 每步完成配一句科普短句 + TTS：「种子喝了水，才能鼓起来发芽哦」
2. **动物爱吃什么**（feed-animals，点选）
   - 出示动物卡（🐰🐼🐨🐸🐹🦁），下方 3-4 张食物卡（🥕🎋🍂🐛坚果🍖），点对的喂食：动物张口 emoji 切换 + 咀嚼音效；喂错：动物摇头 + 食物弹回
   - 首版 10 组动物-食物对；干扰食物从「同类别易混」取（给🐰的干扰里放🍃不吃、🥕吃）
3. **长大排序**（life-cycle，点选排序——复用排序题交互骨架）
   - 生命周期 3-4 阶段卡打乱，按时间顺序点排：🌰🌱🌿🌻 ｜ 🐸↔小蝌蚪系列（素材与 tadpole-story 风格对齐：卵→蝌蚪→长腿→青蛙）｜ 🥚🐣🐓 ｜ 毛毛虫→茧→🦋
   - 首版 4 条生命周期；错序抖回；排对后整列播放「快进生长」动画

### 科普文案纪律（本游戏特有）

每句 ≤15 字、只陈述可直观观察的事实、不引入幼儿无法验证的因果（「喝了水才能发芽」✅，「光合作用」❌）。开发 agent 写初稿 → 审查员之一专职核对常识性（BACKLOG 担心的审核成本，落到质量管道解决）。

### 难度

AdaptiveDifficulty：L1→L2 食物选项 3→4、生命周期 3 阶段→4 阶段；L2→L3 种植物步骤 4→6、动作卡混入 1 个无用动作（🧹扫落叶对向日葵无效，点了摇头提示）。

### 音效语音

浇水 = 白噪声短促下行；生长阶段切换 = 上行琶音；喂食成功 = 咀嚼（低频脉冲 ×3）。TTS 读科普句。

### 素材与行数

全 emoji + CSS。预估 ~800 行；超线砍法：种植物 3 株→2 株。

### 验收标准（E2E）

种植物模式漏步/错序不晋级断言、完整一株四阶段动画走通；喂食答错弹回断言；排序模式整局；科普句 TTS 随音量；三处注册 + 计数 24→25。

## 3. T4-3 创意工坊（craft-workshop.html）

**gameId** `craft-workshop` ｜ **建议批次** 6-A ｜ **品类** 🎨 美术绘画 ｜ **年龄** 3-6 岁 ｜ **卡片** ✂️ ｜ **accent** `#8854d0`
**一句话**：折纸、拼贴、听乐器，做出自己的小作品。
**核心复用**：涂色工坊（coloring-studio.js）已验证的**作品保存 + A4 打印管线**（姓名日期栏、横竖版式）——本游戏是这套框架的第二个消费者，把「创作类游戏产出可打印作品」沉淀为可复用模式。

### 模式结构（三模式）

1. **折纸学堂**（origami-steps，跟做打勾 + 步骤排序）
   - 选一个折纸作品（首版 4 个：小狗头🐶 / 纸船⛵ / 纸飞机✈️ / 青蛙🐸），进入分步引导：每步一张极简 SVG 示意图（10-15 行 path 的折线线稿：虚线=折线、箭头=方向）+ 一句话指令 + TTS 朗读
   - 双层玩法：a) 跟做模式——真纸跟折，每步做完点「这步完成✓」，全部勾完出「作品完成卡」（作品名 + 大 emoji + 星星）可直接打印；b) 步骤排序挑战——步骤卡打乱按序点排（复用排序交互），考验记忆
   - 示意图成本控制：4 作品 × 4 步 = 16 张极简线稿，每张一个 `<symbol>` 复用箭头/虚线定义
2. **撕纸拼贴**（collage，自由创作拖拽）
   - 选背景模板（首版 3 个：鱼缸🐟 / 花园🌸 / 夜空🌙，CSS 渐变场景 + 少量定位装饰），打开贴纸盘（20+ emoji/几何图形贴纸），拖入场景自由摆放；点中的贴纸可再点操作条：放大/缩小（两档）/换色（三色 tint）/删除
   - 无对错：放满 5 个贴纸亮起「完成」按钮（不强制），点击出庆祝 + 作品卡打印
   - 作品保存：localStorage 存贴纸数组（背景 id + 贴纸 [{emoji,x,y,scale,tint}]），重进可续作（遵循 DATA_POLICY.md）
3. **乐器小百科**（instruments，听音辨物 + 配对）
   - a) 听音辨乐器：播放合成音色，从 3-4 张乐器卡（🎹🎻🎸🥁🎺🔔🪈沙锤）点出是哪件；音色全部 WebAudio 合成（钢琴=正弦+2 次谐波快起慢衰、小提琴=锯齿波+LFO 揉弦、鼓=低频下扫+噪声瞬态、小号=方波+音头噪声、铃=不谐和高频簇长衰减、笛=正弦+气声、吉他=三角波快衰减、沙锤=带通噪声短促）
   - b) 演奏方式配对：乐器 ↔ 演奏工具（🎻↔弓、🥁↔鼓槌、🪈↔嘴吹、🎹↔手指），四选一点选
   - 8 音色合成器约 120 行，独立成 `_instrument(name)` 工厂

### 难度

AdaptiveDifficulty：听音选项 3→4、配对选项 3→4；折纸排序 4 步固定（步骤数由作品定，不做自适应维度）。拼贴模式无难度（自由创作）。

### 音效语音

8 乐器音色如上；贴纸落位 = 纸张轻响（短噪声脉冲）；折纸每步勾选 = 纸张摩擦（带通噪声 80ms）。TTS 读折纸指令。

### 素材与行数

16 张 SVG 线稿 + 3 个 CSS 背景模板 + emoji 贴纸盘。预估 ~900 行（本批最大）：超线砍法——折纸跟做与排序二选一首发（留跟做，砍排序），乐器配对子模式 b) 移二期。

### 验收标准（E2E）

折纸 4 步全勾出作品卡、打印按钮可触发（mock window.print 断言）；拼贴拖入 5 贴纸亮完成按钮、存档重进恢复；听音模式 AudioContext mock 下断言 8 音色 tone 调用、拔 voices/静音降级不崩；三处注册 + 计数 25→26。

## 4. T3-5 汉字涂色（hanzi-coloring.html，拼音火车二期）

**gameId** `hanzi-coloring` ｜ **建议批次** 7 ｜ **品类** 🌈 认知启蒙·语文 ｜ **年龄** 4-6 岁 ｜ **卡片** 🖌️ ｜ **accent** `#f7b731`
**一句话**：一笔一笔描一描，把汉字「涂」出来。

### 前置调研结论：笔顺数据源（批次启动的前提，已调研）

- **选定**：[makemeahanzi](https://github.com/skishore/makemeahanzi) 的 `graphics.txt`（Hanzi Writer 同源数据）——每字含 outlines（轮廓 path）+ medians（笔中心线坐标），Arphic 公众授权，可免费商用
- **用法**：写一次性脚本 `tools/extract-hanzi.mjs`，从 graphics.txt 提取 50 字 → 生成 `js/games/hanzi-data.js`（内联字典，符合零运行时依赖）；只取 medians + outlines 精简版，目标单文件 <300KB，sw PRECACHE 收录
- **否决备选**：手绘 50 字 SVG（工作量 50×，质量不可控）；运行时引 Hanzi Writer CDN（违反零依赖协议）

### 首版 50 字表（最终分组以数据源实际笔画数校验）

- A 组（1-4 画，19 字）：一 二 三 十 人 大 天 小 山 上 下 口 日 月 木 火 水 云 风
- B 组（5-7 画，17 字）：田 石 白 生 鸟 花 虫 羊 耳 目 手 足 竹 果 见 车 门
- C 组（8-12 画，14 字）：我 爸 妈 家 猫 狗 米 面 饭 学 雨 飞 高 开 心

### 模式结构（三模式）

1. **笔顺描红**（trace，本游戏核心新交互）
   - 大字 SVG 出示（outlines 淡灰 + 当前笔 median 高亮为粗轨道），手指/鼠标沿轨道滑动；采样点距 median 中线 ≤ 容差即计入覆盖，**当前笔覆盖率 ≥50% 即点亮该笔**（幼儿容差从宽：轨道宽 = 笔宽 ×3）
   - 逐笔推进：完成一笔亮一笔（点亮 = 轮廓填充色从灰变彩）；整字完成播放「涂色」奖励动画（逐笔彩虹填充）+ 字音 TTS
   - 撤销不需要（涂错了继续涂即可）；笔画中途抬起手指不罚，落回继续
2. **笔顺排序**（stroke-order，点选排序）
   - 打散的目标字笔画卡（每笔一个小 SVG，按 medians 单笔渲染），按正确顺序点选入列；点错抖回；排对一笔该笔画入列高亮；整字排完出完整字 + 字音
3. **听音找字**（find-char，点选）
   - TTS 读字音，3-4 张大字卡选对的（数据联动拼音火车的「字-音」关系，但字表独立）；无 TTS 设备降级为「看拼音找字」（拼音火车同款降级模式）

### 难度

AdaptiveDifficulty：L1 = A 组 + 选项 3；L2 = A/B 组混 + 选项 4、描红字 4-7 画；L3 = 含 C 组 + 描红字 8 画以上。答错留题重试。

### 音效语音

逐笔点亮 = 短促水彩「上色」音（正弦滑音）；整字完成 = celebrate；TTS 读字音与鼓励语。

### 素材与行数

主 HTML 预估 ~750 行 + hanzi-data.js（数据文件，不计红线，<300KB）+ tools/extract-hanzi.mjs（一次性工具，不部署）。风险最大点是描红覆盖判定——实现为纯函数 `strokeCoverage(points, median)` 便于 E2E 直接喂数据断言。

### 验收标准（E2E）

50 字数据完整性断言（每字有 outlines+medians+笔画数）；描红覆盖率函数纯数据断言（50% 边界）；排序模式错序抖回；听音模式拔 voices 降级为看拼音；三处注册 + 计数 26→27。

## 5. T4-5 地图、职业与节日（atlas-jobs-festivals.html）

**gameId** `atlas-jobs-festivals` ｜ **建议批次** 8（最后） ｜ **品类** 🌈 认知启蒙·通识 ｜ **年龄** 4-6 岁 ｜ **卡片** 🗺️ ｜ **accent** `#1e3799`

### 模式结构（三模式）

1. **拼大地图**（china-map，拖拽拼图）

   - 拼完整张地图亮灯 + 大区逐个报名字（TTS）；二轮玩法：点「XX 区在哪里」点选模式（反向测验）

2. **职业好朋友**（jobs-match，配对点选）
   - 题面：职业卡（👨‍🚒👩‍⚕️👨‍🍳👮👩‍🌾👨‍✈️👩‍🏫🧑‍🔬）+ 问题「谁用听诊器🩺救病人？」，四选一点职业；或反向「消防员叔叔的宝贝是什么？」四选一工具（🧯🩺🍳🚓）
